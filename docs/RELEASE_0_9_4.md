MoonMMDB v0.9.4 减少联合查询桥接中的中间 JSON 对象分配，保留现有公开 API、完整解码、资源检查和类型化结果格式。

- 直接输出联合查询 JSON，精确保留大整数、浮点位、Unicode、字段缺失及单库错误。
- 增加全部值类型、控制字符和最大解码深度的序列化对照测试。
- 字段查询逐项解码、校验全部内容，仅保留请求的值，减少无用容器及文本分配；隐藏字段的错误和原有资源预算保持不变。
- 增加字段保留、隐藏损坏数据、重叠路径、数组位置、结果隔离与 UTF-8 边界对照测试。
- 递归成功路径减少结果包装与映射键包装，终止错误按操作隔离；64 位读取减少中间大整数分配，保留精确位值。
- 分配诊断覆盖实际桥接路径；默认 Node 配置、持续运行负载和内存门槛保持不变。

安装：`moon add HhWw96/moonmmdb@0.9.4`。下载 Windows/Linux x64 程序或独立离线 HTML，也可使用[本地数据库工作台](https://hhww96.github.io/moonmmdb/)。数据库和日志均在本机处理。

附件校验值见 `SHA256SUMS`。验证报告保留历史失败记录，并绑定本版源码、产物、数据库及运行环境。
