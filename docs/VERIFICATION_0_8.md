## 正确性与使用验收

既有 JS、WasmGC 各 48 项核心测试、33 项 Node 测试、独立参考、强类型包、分析场景、合成规模及打包消费者全部继续执行。0.5.0 核心/bridge 与 0.6.0 核心/bridge/geo 冻结声明保持兼容。

浏览器 Worker 对全部 73 个固定官方 MMDB 文件执行适用的打开、查询和检查预期，并加入固定 DB-IP City / ASN 各 7,114 个地址。每个浏览器与打开方式独立执行 31,259 次查询，包括正常 Python 参考与已审阅异常策略；测试不使用 MoonBit 自身结果生成答案。Anonymous 参考器枚举异常继续依照官方源数据地址与逐 IP 参考结果判断。覆盖 73 个文件不等于移植每个上游读取器断言，也不是商业 Enterprise 大库验证。

UI 与传输检查包含人工 ASN 和标签更新、未命中/字段缺失、非法 IP/路径、隐藏损坏节点、预算不足、下载报告、复制拒绝回退、中文和非 BMP 文件名、预览与结果上限、恶意字符串按文本显示、取消真实 City 检查后重新加载及旧结果隔离。文件超限预检使用合成 File 元信息验证读取前拒绝，避免为边界检查实际分配超限数据库。

`file://` 测试在全新隔离浏览器上下文先禁用网络，再打开生成的 HTML，包含三个内置样例和自选文件；检查请求仅有页面及本地 Blob/data 资源。页面不使用浏览器持久存储。在线访问托管页面本身仍是网络访问，不能据此宣称网站访问没有日志。

本机 Edge `153.0.4234.32` 完成 HTTP 13 项基础检查，回执明确为 `smoke-only`，没有冒充完整独立对照或本机离线验证。本机磁盘不足导致一次完整测试中断，完整规模与离线门槛由隔离 CI 执行。内置浏览器安全策略不允许本机 file://，没有绕过该限制。

## 持续运行方法

Windows、Linux 的隔离 Chromium 分别持续 30 分钟，交替查询和比较、每分钟结构/解码检查、每两分钟终止并重建 Worker、重载真实 City＋ASN。逐次核对相同参数结果无漂移，确认同时只有一个 Worker。不强制 GC。

每 30 秒采样隔离浏览器进程树，RSS 为各进程求和（共享页可能重复计数），Windows 同时记录私有内存。预热五分钟后比较前后各十个样本中位数，增长不得超过 64 MiB 与早期值 25% 的较大者。文件与辅助状态预算不等于进程内存上限。

| 平台 | 秒数 | 查询/对比轮数 | 重载次数 | 最大 Worker 数 | RSS 中位数增长 | Windows 私有内存增长 |
|---|---:|---:|---:|---:|---:|---:|
| Windows 2022 | 1800.012 | 13,616 | 15 | 1 | -11,646,976 B | 5,193,728 B |
| Ubuntu 22.04 | 1800.069 | 13,108 | 15 | 1 | 28,915,712 B | 不适用 |

Windows RSS/私有内存允许增长均为 67,108,864 B；Linux RSS 允许增长为 158,399,488 B（早期中位数的 25%）。所有趋势门槛通过，无崩溃或结果漂移。原有 Native 的 enrich-many、diff、游标/检查三种 30 分钟负载也在两平台全部通过，报告保存在同一证据目录。

[完整报告索引](../verification/releases/0.8.0/evidence-index.json) 保留原始 JSON 的 SHA-256。历史 Node 默认 RSS 门槛失败继续保留；浏览器或 Native 通过不表示该问题已修复。
