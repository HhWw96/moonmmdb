`node scripts/release-verify.mjs [Python路径]` 在同一轮串行执行上述检查、独立参考、规模对照、包消费和性能测量；开始即写 running，失败写 failed。release.json 绑定运行源码、测试数据、验证脚本、构建产物与各报告的 SHA-256。交付器拒绝源码、字节码、证据文件变化后继续使用旧记录。报告不包含“无缺陷”或“已获奖”结论。

测试数不是完备性证明。变异测试验证这组输入不产生未处理异常，不要求所有修改后的文件都被拒绝，也不保证检出了所有数据损坏。

## 参考实现分歧与验证范围

固定 `maxminddb==3.2.0`。在本机 C 扩展路径中，`MaxMind-DB-test-decoder.mmdb` 的 `255.255.255.255` 记录把 UInt32 最大值输出为 -1；纯 Python 与 MoonMMDB 都输出 4294967295。测试针对这个具体平台、文件、地址和值组合记录已知分歧，其余差异仍会失败；没有普遍把负数自动修正为无符号数。独立类型用例也校验了该边界。

参考的 metadata-pointers 样例仅做元数据比较；no-ipv4-search-tree 样例使用固定边界和随机地址，没有依赖其会抛错的参考网络迭代器。检索/测试中出现过的失败与修正说明被保留，没有将参考工具全部标记为完美。

官方样本固定到 MaxMind-DB `7fcd868842970b2d0657af799807cbe722fb738d`。不包含生产 GeoLite2/GeoIP2 全量库；样本里的 IP 归属是人工示例，不作为现实信息使用。

## 性能初测

Windows / AMD Ryzen 7 5800H；JS release 构建；每库打开 100 次、预热 200 次、查询 10,000 次。查询包含 MoonBit 的类型化 JSON 序列化，文件读取不计入查询循环。结果随硬件、运行环境与查询分布变化。

| 人工测试库 | 大小 | 平均打开并输出元数据 | 平均查询并输出 JSON |
|---|---:|---:|---:|
| ASN | 12,653 字节 | 约 0.62 ms | 约 17.65 μs |
| City | 22,569 字节 | 约 0.30 ms | 约 105.97 μs |

这是小样本基线，不是完整数据库吞吐承诺，不宣称快于 C/Python。打开含输入快照复制；进程内存记录覆盖整个基准运行，不是单个 Reader 的精确占用。完整数据与编译产物散列值保存在 benchmark.json。

规模库本机初次完整发布验证：约 31 MB，打开约 221 ms；预热 200 次后查询 5,000 次，平均约 38.13 μs。这里同时包含宿主 JSON.parse 并保留输出做对照；峰值 RSS 约 122 MiB，包含文件、快照、运行时及保留结果。它不是 Reader 单独内存、商用库真实负载或跨语言性能比较。不同验证运行的原始值以交付包内的 scale.json / benchmark.json 为准，表中数值是具体一次观测。
